# Oracle

**Status: limits and type ranges are from Oracle's documentation; the casts below are a draft and have not been run yet.** Test them on Oracle in the Lima VM (the arm64 `gvenzl/oracle-free` image, see **lfc-source-podman**) with a boundary test like the Postgres and MySQL ones before relying on them, and update this file with what passes.

## Plan

The same design as the tested engines: a catalog query (`ALL_TAB_COLUMNS`, `ALL_CONSTRAINTS`, `ALL_CONS_COLUMNS`) writes one `INSERT ... SELECT` per table; each INSERT reads its own min and max key; targets live in the table comment (`COMMENT ON TABLE t IS 'lfc:rows=500000'`, read from `ALL_TAB_COMMENTS`).

| Piece | Oracle form |
|---|---|
| Row source up to 10,000 | `SELECT LEVEL AS i FROM DUAL CONNECT BY LEVEL <= n` |
| Seed table | Before 23ai, `INSERT ... VALUES` takes one row: fill 1..1000 with `INSERT INTO lfc_seed SELECT LEVEL FROM DUAL CONNECT BY LEVEL <= 1000`, then double with `INSERT INTO lfc_seed SELECT i + (SELECT MAX(i) FROM lfc_seed) FROM lfc_seed` |
| Max key | `SELECT MAX(<key>) FROM t` uses `INDEX FULL SCAN (MIN/MAX)` on the primary key; `ORDER BY <key> DESC FETCH FIRST 1 ROW ONLY` also works (12c+) |
| Delete from one end | `DELETE FROM t WHERE <key> <= (SELECT <key> FROM t ORDER BY <key> OFFSET k - 1 ROWS FETCH NEXT 1 ROW ONLY)` (`DESC` and `>=` for the tail) |
| Identity keys | `GENERATED BY DEFAULT` accepts explicit keys; `GENERATED ALWAYS` rejects them (alter the column, or skip the table) |
| Parallel insert | `ALTER SESSION ENABLE PARALLEL DML;` then `INSERT /*+ APPEND PARALLEL(t, 4) */ INTO t SELECT ...`. Direct-path inserts write above the high-water mark, and the session must `COMMIT` before it reads the table again |

## Types

`n` is the row's `NUMBER`. Draft casts; none tested yet.

| Category | Types | Range | Draft value from `n` | Key |
|---|---|---|---|---|
| Number | `NUMBER(p,s)` (p 1 … 38, s −84 … 127), `NUMBER`, `INTEGER` / `INT` / `SMALLINT` (= `NUMBER(38)`), `FLOAT(p)` (binary p 1 … 126), `DECIMAL`, `NUMERIC` | below 10^(p−s) | `MOD(n, 10^min(p,18)) * POWER(10, -s)` (exact decimal arithmetic); `n` | `NUMBER(p,0)`, `INTEGER` |
| Binary float | `BINARY_FLOAT`, `BINARY_DOUBLE` | IEEE single / double | `TO_BINARY_FLOAT(n)`, `TO_BINARY_DOUBLE(n)` | — |

| LOB | `CLOB`, `NCLOB`, `BLOB` | | `TO_CLOB(<100-character string>)`; `TO_NCLOB(...)`; `TO_BLOB(<RAW>)` | — |
| Binary | `RAW(L)` (L ≤ 2,000; 32,767 extended) | | `HEXTORAW(SUBSTR(LPAD(TO_CHAR(n, 'FMXXXXXXXXXXXXXXXX'), 16, '0') \|\| RAWTOHEX(STANDARD_HASH(TO_CHAR(n), 'MD5')), 1, 2 * L))` | — |
| Date / time | `DATE` (includes a time; −4712 … 9999), `TIMESTAMP(p)` (p ≤ 9), `TIMESTAMP WITH TIME ZONE`, `TIMESTAMP WITH LOCAL TIME ZONE` | | `DATE '1970-01-01' + MOD(n, 2932896)`; `TIMESTAMP '1970-01-01 00:00:00' + NUMTODSINTERVAL(MOD(n, 2932896), 'DAY') + NUMTODSINTERVAL(MOD(n, 86400), 'SECOND')` (two small intervals avoid ORA-01873); `FROM_TZ(<timestamp>, '+00:00')`; `CAST(FROM_TZ(...) | Interval | `INTERVAL YEAR(p) TO MONTH`, `INTERVAL DAY(p) TO SECOND(f)` (p default 2) | leading field below 10^p | `NUMTOYMINTERVAL(MOD(n, 12 * (10^p - 1)), 'MONTH')`; `NUMTODSINTERVAL(MOD(n, 86400 * (10^p - 1)), 'SECOND')` | — |
| Boolean | `BOOLEAN` (23ai+) | | `CASE MOD(n, 2) WHEN 1 THEN TRUE ELSE FALSE END` | — |
| JSON, XML | `JSON` (21c+), `XMLTYPE` | JSON 32 MB | `JSON_OBJECT('n' VALUE n RETURNING JSON)`; `XMLTYPE('<n>' \|\| n \|\| '</n>')` | — |
| Spatial | `SDO_GEOMETRY` | | `SDO_GEOMETRY(2001, 4326, SDO_POINT_TYPE(MOD(n, 180) - 90, MOD(n, 89), NULL), NULL, NULL)` | — |
| Not supported | `ROWID`, `UROWID`, `BFILE` (points to an external file), `LONG`, `LONG RAW` (deprecated); `VECTOR` (23ai) until tested | | | |

## Gotchas (from the docs)

- **An empty string is `NULL`** in `VARCHAR2` and `CHAR`.
- **`DATE` includes a time**, so `DATE + 1` adds a day and a fraction adds part of one.
- **Interval overflow (ORA-01873)** when a value exceeds the interval's leading precision: keep each interval small, as in the casts above.
- **Redo and undo:** a large load writes redo (and archived logs, which CDC reads). Size the archive destination, or load before enabling supplemental logging for CDC.
